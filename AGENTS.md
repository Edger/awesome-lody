# Repository guidance

This repository shares Lody community resources. Keep scenario → content type → entry layout. The v1 contract is in docs/format.md and docs/format.zh-CN.md.

- Keep root documentation, contribution guides, format docs, and templates bilingual. Submissions may be monolingual and declare languages.
- Only roles, schedules, and prompts require configuration YAML. Prompt bodies live in separate Markdown files. Shortcuts are plain text in v1.
- Articles/videos use one Markdown file. Full Skills retain their SKILL.md contract; external Skill recommendations are allowed.
- Use MIT for original contributions; preserve third-party licenses and attribution.
- Do not execute contributed scripts or tasks during review. Document current workflows only; do not publish unannounced product plans.
- Keep this a document and resource collection. Do not introduce an application runtime, package manager, dependency installation, or mandatory build/test workflow.
- Review metadata, configuration fields, local file references, and bilingual documentation when making changes. schemas/ describes field shapes; templates/ provides copyable examples.
- Do not add empty scenario directories or present templates as verified community entries.
